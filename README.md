# NOVA

AI-Powered Smart Tourism Planner

## Project Overview

NOVA is a full-stack smart tourism platform that helps tourists discover destinations, create personalized trips, generate AI-powered itineraries, manage bookings and explore travel recommendations.

## Technology Stack

- ASP.NET Core Web API
- PostgreSQL
- React
- Flutter
- Agentic AI
- GitHub Actions

## Project Structure

- `backend` - ASP.NET Core Web API
- `web` - React web application
- `mobile` - Flutter mobile application
- `ai-service` - Agentic AI service
- `database` - Database scripts and migrations
- `docs` - Project documentation
- `tests` - Testing resources
